# Pranay Mobiles — Mobile Store & Repair Website (MERN)

A multi-page, Apple-inspired electronics store with an integrated phone-repair booking system and an admin dashboard.

**Business:** Pranay Mobiles  
**Address:** Bank Of India Rd, Ghugus Basti, Ghugus, Maharashtra 442505

- **Frontend:** React 18, Vite, Bootstrap 5, React Router, Motion for React
- **Backend:** Node.js 20+, Express, REST API, Zod validation
- **Database:** MongoDB Atlas via Mongoose
- **Images:** Cloudinary
- **Payments:** Razorpay, with optional Cash on Delivery

Product listings, prices, banners, categories, FAQs, policies, contact details, and repair information are managed through MongoDB and the admin dashboard.
